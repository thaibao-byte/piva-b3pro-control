# PIVA B3PRO Web Controller

Dieu khien tan nhiet **PIVA B3PRO** bang Web Bluetooth.

- Repo: https://github.com/thaibao-byte/piva-b3pro-control
- Pages: https://thaibao-byte.github.io/piva-b3pro-control/

Mo bang **Chrome / Edge** (Android hoac desktop). Can HTTPS.

## Ket noi
1. Cam nguon B3PRO, bat Bluetooth.
2. Bam **Ket noi B3PRO**.
3. Khong thay ten thi bam **Quet tat ca**.
4. Lan sau bam **Reconnect**.
